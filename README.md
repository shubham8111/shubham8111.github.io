# shubham8111.github.io

Source for [shubham8111.github.io](https://shubham8111.github.io/), my personal site.

Plain HTML and CSS, no build step. GitHub Pages serves the `master` branch as-is.

- `index.html`: home page
- `resume/index.html`: web resume, print-friendly
- `assets/site.css`: all styles
- `assets/img/`: photos and project screenshots

To preview locally: `python3 -m http.server` and open http://localhost:8000.
